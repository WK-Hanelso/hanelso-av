## Test coverage decision

이번 round는 artifact contract의 missing file/producer hint, missing required key, unsupported provenance를 data-free `tmp_path` tests로 보강한다. Counterfactual invalid preservation과 deterministic token은 기존 tests가 이미 검증하므로 중복 test를 추가하지 않는다. ([new tests](../tests/test_contract.py#L12-L46), [existing counterfactual tests](../tests/test_counterfactual_schema.py#L41-L65))

Closed-loop simulation unit test는 torch, policy, postprocessor, renderer, map/clip bundle을 함께 요구하므로 작은 data-free test 범위를 벗어난다. 따라서 runtime code-path evidence는 유지하되 automated E2E coverage claim은 하지 않는다. ([driver construction](../simulation/drivers/model_driven.py#L38-L88), [simulation assembly](../simulation/render_sim.py#L85-L137))
